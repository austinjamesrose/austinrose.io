## The Problem

My friends and I run a fantasy football league where we only draft quarterbacks. We were tracking stats by hand every few weeks, so the standings ran behind and nobody knew where they stood until someone updated the spreadsheet.

## The Solution

I built qbleague.xyz in a night using Claude Code. It pulls QB stats and calculates scores against our custom rules, so standings update as games finish instead of whenever someone remembers to do the math.

## How It Works

The site pulls official NFL data via nflreadpy, tracking passing yards, rushing yards, touchdowns, interceptions, and QB wins. Our scoring system has some quirks, including extra credit for prime time wins, and the site handles them without input from us.

## What's Next

This is fresh, and we haven't run a full season with it yet. The spreadsheet is retired either way.
